# DEVPIRA Festival 2026

Este repositório é destinado ao compartilhamento das apresentações dos palestrantes do DEVPIRA Festival 2026.

## Guia do palestrante

Consulte o [Guia do Palestrante — DEVPIRA Festival 2026](./Guia%20do%20Palestrante%20—%20DEVPIRA%20Festival%202026.pdf).

## Estrutura das pastas

Os arquivos devem ser enviados para a subpasta com o título da apresentação, dentro da pasta correspondente à trilha:

- `Inteligência Artificial`
- `IA Agêntica`
- `Agilidade & Fluxo`
- `Produto & Valor`
- `Arquitetura & Infra`
- `Carreira, Web & Fundamentos`
- `Workshops`
- `Material de Design`

A pasta `Workshops` contém as subpastas das oficinas. A pasta `Material de Design` contém recursos visuais compartilhados:

- [Logo preto](Material%20de%20Design/DEVPIRA10Preto.png) para fundos claros.
- [Logo branco](Material%20de%20Design/DEVPIRA10Branco.png) para fundos escuros.
- O QR code para avaliação NPS das palestras aparece nas três sugestões de uso abaixo e também está disponível como [imagem isolada](Material%20de%20Design/QRCodeNPSPalestras.jpeg). O formulário pode ser acessado pelo [link do NPS](https://forms.gle/T8TVM2y7TqgfmJDh6).

### Sugestões de uso

1. **Encerramento com convite à avaliação e sorteio:** use a [sugestão 1](Material%20de%20Design/Sugest%C3%A3o%20de%20uso%201.png) no slide final da palestra ou do evento.
2. **Agradecimento ao público:** use a [sugestão 2](Material%20de%20Design/Sugest%C3%A3o%20de%20uso%202.png) no último slide da apresentação.
3. **Chamada para avaliar a palestra:** use a [sugestão 3](Material%20de%20Design/Sugest%C3%A3o%20de%20uso%203.png) em um slide de avaliação, mantendo o QR code em destaque para facilitar o acesso ao formulário.

## Como adicionar ou atualizar uma apresentação

1. Localize a pasta da sua trilha.
2. Entre na subpasta com o título da sua apresentação.
3. Adicione o arquivo da apresentação nessa subpasta.
4. Mantenha os recursos compartilhados na pasta `Material de Design`.
5. Envie as alterações por meio de um pull request para a branch `main`; não altere a `main` diretamente.

Para isso, crie uma branch neste repositório ou, se não tiver permissão, faça um fork. Depois de enviar suas alterações à branch, abra um pull request para `main` e informe a trilha e o título da apresentação.
